The standard

Improv Wi-Fi

A free and open standard for setting up Wi-Fi over Bluetooth LE or serial. An initiative by ESPHome and Home Assistant, with development funded by Nabu Casa.

  • improv-wifi.com: specification, SDKs, adopters
  • Bluetooth LE specification
  • Serial specification

impromptu-wifi is an independent Rust implementation. It is not affiliated with or endorsed by the Improv Wi-Fi project.

    How Improv works

    1. 01A device without a network starts and offers Improv over Bluetooth LE, serial, or both.
    2. 02A client, such as a phone, a browser or a command-line tool, sends a network name and passphrase.
    3. 03The device joins the network and reports success, often with an address where it can be reached.
    4. 04You open that address to finish setting up the device.

    What this implementation adds

    Both roles

    The device being set up and the client that sets it up, on one protocol core.

    no_std crates without allocation, with an ESP32-S3 example.

    Linux

    A daemon that makes a Linux machine, such as a Raspberry Pi, provisionable over Bluetooth LE and serial.
