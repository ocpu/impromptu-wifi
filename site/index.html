About the standard

Improv Wi-Fi

Improv Wi-Fi is a free and open standard for putting a device on a Wi-Fi network over Bluetooth LE or a serial connection. It is an initiative by ESPHome and Home Assistant, with development funded by Nabu Casa.

The specification, official SDKs and the list of projects that use it are at improv-wifi.com: Bluetooth LE specification · serial specification · github.com/improv-wifi.

impromptu-wifi is an independent Rust implementation. It is not affiliated with or endorsed by the Improv Wi-Fi project.

How Improv works

  1. A device without network access starts and offers Improv over Bluetooth LE, serial, or both.
  2. A client, such as a phone, a browser or a command-line tool, connects and sends a network name and passphrase.
  3. The device joins the network and reports success, optionally with a URL where it can be reached.
  4. The user opens that URL to finish setting up the device.

Try it

Provision an Improv device from this page. It runs the impromptu-wifi client, compiled from Rust to WebAssembly, in your browser; the network name and passphrase go only to the device you choose.

    What this implementation adds

    • Both roles

      The device being provisioned and the client that provisions it, sharing one protocol core.

    • Firmware

      no_std crates without allocation for embedded devices, with an ESP32-S3 example.

    • Linux

      A daemon that makes a Linux machine, such as a Raspberry Pi, provisionable over Bluetooth LE and serial.

    • Command line

      A CLI that provisions devices over serial or Bluetooth LE, and this page for the browser.

    The support matrix lists the devices, systems and clients that have been tested.
